                    QUICKMENU — БЫСТРОЕ МЕНЮ ДЛЯ WINDOWS

ЧТО ЭТО
--------
Простое текстовое меню в командной строке. Перемещаетесь стрелками, запускаете
Enter'ом, добавляете и удаляете пункты прямо на лету. Все настройки сохраняются.


ФАЙЛЫ
------
menu.bat     — запускалка (вызывает PowerShell с правильными параметрами)
menu.ps1     — само меню (управление стрелками, добавление, удаление)


УСТАНОВКА
---------
1. Создайте папку:
       C:\Tools

2. Скачайте два файла menu.bat и menu.ps1 с GitHub.

3. Добавьте C:\Tools в системную переменную PATH:
       Win+R → sysdm.cpl → Дополнительно → Переменные среды →
       → Path → Изменить → Создать → введите C:\Tools → ОК (во всех окнах)

3. Перезапустите окно cmd.


ЗАПУСК
-------
Только из командной строки (cmd):
       Win+R → cmd → menu

Не запускайте из PowerShell — сработает политика безопасности и меню
не откроется.


УПРАВЛЕНИЕ В МЕНЮ
-----------------
↑ ↓       — выбор пункта
Enter     — запуск программы
A         — добавить новый пункт
Del       — удалить выбранный пункт
Esc       — выход

При добавлении (A):
   Имя      — любое название (например: VS Code)
   Команда  — что запускать. Это может быть:
              • имя программы:        notepad
              • команда в PATH:       code, docker
              • полный путь к .exe:   "C:\Program Files\App\app.exe"
              • папка:                D:\Downloads
              • ссылка:               https://google.com

Если в пути есть пробелы — обязательно берите его в кавычки при добавлении.


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Все пункты сохраняются в файле:
       %APPDATA%\QuickMenu\items.txt
(обычно C:\Users\ИМЯ\AppData\Roaming\QuickMenu\items.txt)

Формат простой: одна строка = один пункт.
       Имя=команда

Можно править файл вручную в Блокноте. Изменения подхватятся при следующем
запуске меню.


ПРИМЕРЫ ПУНКТОВ ДЛЯ ДОБАВЛЕНИЯ
-------------------------------
Блокнот              notepad
Калькулятор          calc
Paint                mspaint
VS Code              code
Docker Desktop       "C:\Program Files\Docker\Docker\Docker Desktop.exe"
Проводник            explorer
Папка Загрузки       C:\Users\%USERNAME%\Downloads
Google               https://google.com


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
• "Не является внутренней или внешней командой" — проверьте, что C:\Tools
  добавлен в PATH и окно cmd открыто ПОСЛЕ изменения PATH.
• "Не удается загрузить файл... не имеет цифровой подписи" — вы запустили
  menu из PowerShell. Открывайте через cmd.
